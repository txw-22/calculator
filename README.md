## 프로젝트 소개

**Warm Glass Calculator**는 HTML, CSS, JavaScript만으로 만든 웹 계산기입니다. 기존 사칙연산 계산기에 사용성과 시각적 완성도를 더하기 위해 계산 상태 관리 로직을 개선하고, 글래스모피즘 인터페이스와 버튼별 **Soft Click** 효과음을 적용했습니다.

**핵심 개발 목표**

- 계산 흐름에 따라 달라지는 입력 상태와 예외 상황을 안정적으로 처리하기
- 계산 과정·결과를 구분하고 긴 숫자도 읽을 수 있도록 표시하기
- **피치·베이지·브라운** 컬러의 반투명 유리 UI를 반응형으로 구성하기
- 라이브러리·오디오 파일 없이 **Web Audio API**로 키패드 피드백 제공하기

## 주요 기능

| 기능 | 구현 내용 |
| --- | --- |
| 사칙연산 | `+`, `−`, `×`, `÷` 버튼과 키보드 입력 지원 |
| 계산 상태 관리 | 연속 계산, 연산자 변경, 등호 이후 새 계산 시작 구분 |
| 소수점·부호·백분율 | 소수점 중복 입력 방지, `+/−` 부호 전환, `%`는 **현재 입력값 ÷ 100** |
| 오류 처리 | 0으로 나누기 또는 유한하지 않은 결과에 `Error` 표시, 이후 새 숫자 입력으로 복구 |
| 계산 과정 표시 | 입력 중인 연산 및 등호 계산식을 결과 상단에 표시 |
| 키보드 | 숫자, `.`, `+ − * /`, `Enter`, `=`, `Backspace`, `Delete`, `Escape`, `C` 등 |
| Soft Click | 숫자·연산자·등호·초기화에 서로 다른 짧은 클릭음 합성 |
| 소리 설정 | 기본 OFF, ON/OFF 버튼, `localStorage`에 선택 상태 저장 |
| 반응형 디자인 | CSS Grid 기반 4열 키패드, 작은 화면에서 버튼·간격·글자 크기 조정 |

> **계산 방식:** 연산자를 입력한 순서대로 중간 결과를 계산합니다. 예를 들어 `10 + 5 × 2 =`의 결과는 `30`입니다. 괄호나 일반 수학식의 연산자 우선순위를 구현한 계산기는 아닙니다.

## 디자인과 사용자 경험

- **Warm Glassmorphism:** 따뜻한 그라데이션, 반투명 배경, `backdrop-filter`, 얇은 테두리와 부드러운 그림자
- **가독성:** 웜 그레이 숫자 버튼, 브라운 연산 버튼, 우측 정렬 결과 표시
- **버튼 구성:** 원형 키패드, 가로형 `0` 버튼, 세로 비율이 강조된 `=` 버튼
- **긴 숫자 대응:** 자릿수에 따른 글꼴 크기 조절과 가로 스크롤 지원
- **입력 피드백:** 클릭/터치/키보드 이벤트에서 동일한 계산 동작과 소리 제공
- **사용자 선택 존중:** 소리 기본 OFF, 브라우저에 설정 기억, 동작 감소 선호(`prefers-reduced-motion`) 스타일 반영

## 기술 스택

| 기술 | 사용 목적 |
| --- | --- |
| **HTML5** | 시맨틱 레이아웃, 계산기 버튼, `data-*` 기반 입력 정의 |
| **CSS3** | CSS Grid, 반응형 스타일, 글래스모피즘, 키패드 인터랙션 |
| **Vanilla JavaScript** | DOM 업데이트, 이벤트 처리, 연산 상태 관리 및 오류 복구 |

| **localStorage** | 사운드 ON/OFF 설정 보관 |
| **GitHub Pages** | 정적 사이트 배포 |

## 문제 해결 과정

### 1. `0`으로 나눴을 때 후속 계산이 꼬이는 문제

`8 ÷ 0 =`에서 `Error`를 표시하는 것으로 끝내지 않고, 이전 피연산자·연산자·대기 상태를 초기화하여 이후 숫자 입력으로 새로운 계산을 시작하도록 개선했습니다.

### 2. 이전 계산 결과가 다음 계산에 남는 문제

`5 + 3 = 8` 후 `0.1 + 0.2 =`를 입력했을 때 이전 값이 다음 연산에 섞이지 않도록 `waitingForSecondOperand`, `justCalculated`, `firstOperand` 상태를 구분했습니다.

### 3. 부동소수점 결과와 긴 숫자 표시

`0.1 + 0.2`의 이진 부동소수점 오차를 사용자 화면에서 줄이기 위해 `Number(result.toPrecision(12))`로 결과를 정리합니다. 입력값과 출력 자릿수에 따라 디스플레이 글자 크기를 바꾸고 가로 스크롤을 허용합니다.

> 이 방식은 **일반적인 계산에서 오차를 완화**하는 것이며, 임의 정밀도 계산이나 모든 부동소수점 문제의 완전한 해결책은 아닙니다.

### 4. 사운드 파일 없이 인터랙션 구현

별도 MP3/WAV를 다운로드하지 않고 Web Audio API의 오실레이터, 필터, 볼륨 엔벨로프를 이용해 짧은 클릭음을 합성했습니다. 사운드는 사용자가 직접 켤 수 있고 선택 상태는 브라우저에 저장됩니다.

## 대표 테스트 시나리오

| 입력 | 예상 동작 |
| --- | --- |
| `5 + 3 =` | `8` 표시 |
| 이어서 `0.1 + 0.2 =` | `0.3` 표시 (새 계산 시작) |
| `10 + 5 × 2 =` | `30` 표시 (순차 계산) |
| `8 ÷ 0 =` | `Error` 표시 |
| `Error` 이후 `5 + 3 =` | `8` 표시 |
| `50 × 10 % =` | `5` 표시 |
| 사운드 ON → 새로고침 | 저장된 ON 상태 복원 |

전체 입력 규칙과 검증 항목은 [상세 기능 명세](docs/FEATURES.md)에 정리했습니다. 표는 **예상 결과 기준**이며 브라우저별 실기기 검증 결과와 구분합니다.
