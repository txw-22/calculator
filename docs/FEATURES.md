## 1. 서비스 개요

Warm Glass Calculator는 HTML5/CSS3/Vanilla JavaScript로 구현한 단일 페이지 계산기입니다. 사칙연산, 소수점 입력, 부호 전환, 백분율, 계산 과정 표기 및 키보드 입력을 지원합니다. 키패드 클릭음은 Web Audio API로 실시간 합성하며 별도 음원 파일이나 백엔드 없이 동작하도록 구성했습니다.

### 주요 파일과 책임

| 파일 | 역할 |
| --- | --- |
| `index.html` | `.calculator`, `.display`, `.history-display`, `.buttons`, `#sound-toggle` 및 각 키의 `data-*` 구성 |
| `styles.css` | 컬러 토큰, 배경 광원, 유리 질감, 4열 키패드, 반응형 브레이크포인트 |
| `script.js` | 입력 상태, 연산, 화면 갱신, 키보드·클릭 이벤트, 사운드 합성·설정 저장 |

## 2. 계산 상태 모델

| 상태 변수 | 초기값 | 의미 |
| --- | --- | --- |
| `currentInput` | `'0'` | 표시하고 계산에 사용할 현재 입력값(문자열) |
| `firstOperand` | `null` | 진행 중인 연산의 첫 번째 피연산자 |
| `operator` | `null` | `add`, `subtract`, `multiply`, `divide` 중 선택된 연산자 |
| `waitingForSecondOperand` | `false` | 다음 숫자로 새로운 피연산자를 시작해야 하는지 여부 |
| `justCalculated` | `false` | 직전 동작이 등호 계산의 완료 상태인지 여부 |
| `calculationHistory` | `''` | 결과 위에 보여줄 계산식 문자열 |

### 대표 상태 전환

1. 초기 상태는 화면 `0`, 모든 연산 상태 초기화입니다.
2. 숫자 또는 `.` 입력으로 `currentInput`을 만들고 화면을 갱신합니다.
3. `+`, `−`, `×`, `÷` 입력으로 첫 피연산자와 연산자를 보관하고 다음 숫자 입력을 기다립니다.
4. 두 번째 피연산자 뒤에 연산자를 누르면 **이전 연산을 즉시 계산**한 뒤 새 연산자를 저장합니다.
5. `=` 입력 시 최종 결과와 직전 계산식을 표시하고 `justCalculated` 상태로 전환합니다.
6. 완료 후 숫자 또는 소수점을 입력하면 이전 연산을 폐기하고 새 계산을 시작합니다.
7. `Error` 이후 숫자를 입력하면 계산 상태를 초기화하고 새 숫자를 입력합니다.

## 3. 기능별 세부 규칙

### 3.1 숫자 입력 및 소수점

- 숫자 버튼은 `data-num`을 통해 `inputDigit()`를 호출합니다.
- 현재 표시값이 `'0'`이면 새 숫자로 교체합니다.
- 두 번째 피연산자를 기다리던 중 숫자를 입력하면 기존 값을 덮어씁니다.
- 소수점은 한 입력값에 하나만 허용합니다. `.`으로 시작할 때는 `0.`이 됩니다.
- 계산 완료 후 새 숫자·소수점 입력에서는 이전 연산 상태가 다음 계산에 유입되지 않게 초기화합니다.

### 3.2 사칙연산과 등호

- `calculate(first, second, op)`에서 사칙연산을 수행합니다.
- 연산자 입력 순서대로 계산하는 **즉시 실행형 계산기**입니다. 예: `10 + 5 × 2 =` → `30`.
- 연산자를 연속 누르면 직전 연산자를 마지막으로 누른 연산자로 변경합니다.
- 두 번째 피연산자 없이 `=`를 누르면 현재 로직은 저장된 첫 피연산자를 재사용합니다. 예: `5 + =` → `10`.
- 최종 결과와 계산식을 갱신하고 완료 상태로 전환합니다.
- 반복 `=`에 의한 직전 연산 재실행은 별도로 구현되어 있지 않습니다.

### 3.3 단항 연산

- `+/−`: `toggleSign()`이 현재 숫자의 부호를 변경합니다. `0`은 `0`을 유지합니다.
- `%`: `applyPercent()`가 **현재 입력값을 100으로 나눕니다.** 예: `200 %` → `2`, `50 × 10 % =` → `5`.
- 이 `%`는 계산기별로 정의가 달라질 수 있는 문맥형 백분율(예: `200 + 10 % = 220`)을 구현한 것이 아닙니다.

### 3.4 초기화·삭제·오류

- **AC** 또는 키보드 `Delete`, `Escape`, `C/c`: 계산기를 완전히 초기화합니다.
- **Backspace**: 입력 중 마지막 글자를 삭제하고 한 글자 이하로 줄어들면 `0`으로 표시합니다.
- 연산자 선택 후 다음 피연산자를 기다리는 상태에서는 Backspace가 입력값을 변경하지 않습니다.
- 계산 직후 Backspace를 누르면 계산기를 초기화합니다.
- 0으로 나누거나 `Number.isFinite()`가 `false`인 결과는 `Error`로 표시합니다.
- 오류 처리에서는 피연산자·연산자·계산식 등 계산 상태를 초기화하고, 다음 숫자 입력을 통해 새 계산을 시작합니다.

### 3.5 부동소수점 처리

```js
return Number(result.toPrecision(12));
```

일반적인 이진 부동소수점 오차로 인해 `0.1 + 0.2`가 긴 근삿값으로 표현되는 것을 완화합니다. **12자리 유효숫자 반올림**을 사용하며 임의 정밀도 산술이나 금융용 정밀 계산을 보장하지 않습니다. 화면 표시는 입력 문자열 및 결과 문자열의 길이에 따라 `.is-long`, `.is-very-long` 스타일을 적용합니다.

## 4. 클릭·키보드 입력

| 입력 종류 | 화면 버튼 | 키보드 |
| --- | --- | --- |
| 숫자 | `0`–`9` | `0`–`9` |
| 소수점 | `.` | `.` |
| 덧셈 | `+` | `+` |
| 뺄셈 | `−` | `-` |
| 곱셈 | `×` | `*` |
| 나눗셈 | `÷` | `/` |
| 계산 | `=` | `Enter`, `=` |
| 초기화 | `AC` | `Delete`, `Escape`, `c`, `C` |
| 한 글자 삭제 | 별도 버튼 없음 | `Backspace` |
| 백분율 | `%` | `%` |
| 부호 변경 | `+/−` | 버튼으로 지원 |

키보드 이벤트에서는 Ctrl/Alt/Meta 조합을 우선 제외합니다. 버튼 클릭은 `.buttons`에서 이벤트 위임으로 처리합니다.

## 5. Soft Click 사운드

### 상태와 저장

- 초기값은 **OFF**이며 `localStorage.getItem('calculator-sound') === 'on'`일 때만 ON으로 복원합니다.
- `#sound-toggle` 버튼으로 전환하고 `aria-pressed`, `aria-label`, 아이콘·툴팁을 갱신합니다.
- 설정을 변경하면 `localStorage`의 `calculator-sound` 키에 `on` 또는 `off`를 저장합니다.
- 로컬 저장소 사용이 제한된 환경에서는 예외를 처리하고 계산 기능은 유지합니다.

### 소리 생성

1. 사용자가 버튼이나 키보드를 조작하면 필요 시 `AudioContext`를 생성·재개합니다.
2. `OscillatorNode`의 짧은 triangle 파형을 설정합니다.
3. `BiquadFilterNode`의 low-pass 필터를 적용합니다.
4. `GainNode`로 짧게 커졌다 작아지는 볼륨 엔벨로프를 구성합니다.
5. 사운드가 끝나면 연결 노드를 해제합니다.

숫자, 연산자, `=`, AC에 대해 높낮이·볼륨·재생 시간이 다른 프리셋을 사용합니다. 음원 파일이나 외부 API는 사용하지 않습니다. 브라우저의 자동 재생 정책 및 기기 음소거 상태에 따라 실제 소리가 달라질 수 있습니다.

## 6. UI 및 반응형 명세

### 글래스모피즘 스타일

- **컬러:** 베이지·피치 그라데이션과 웜 그레이 키패드 글자(`#796a60`), 브라운 연산 버튼
- **본체:** 반투명 그라데이션, 보더, 그림자, `backdrop-filter`
- **키패드:** CSS Grid 4열, 원형 숫자 버튼, 가로로 2열을 차지하는 `0`, 길쭉한 캡슐 비율의 `=`
- **디스플레이:** `text-align: right`, `white-space: nowrap`, 가로 스크롤 및 글자 크기 단계 조절
- **반응형:** `480px`, `360px` 너비 구간과 `650px` 이하 높이 구간에 따른 조정
- **모션 선호:** `prefers-reduced-motion: reduce`에서는 버튼 전환 효과 제거

> `=` 버튼은 그리드에서 **실제로 두 행을 차지하는 버튼은 아닙니다.** 스타일의 종횡비와 모서리 반경으로 세로로 긴 형태를 표현합니다.

## 9. 알려진 범위와 다음 개선

1. **정밀도 한계:** JavaScript `Number`와 `toPrecision(12)` 기반으로 초고정밀 계산에 적합하지 않습니다.
2. **연산 문법:** 괄호·연산자 우선순위가 아닌 입력 순서대로 계산합니다.
3. **반복 등호:** 이전 연산 자동 반복 기능이 없습니다.
4. **히스토리:** 현재 계산식 한 줄만 표시하고 과거 계산 이력을 누적 저장하지 않습니다.
5. **데이터 저장:** 사운드 설정만 저장하며 계산 결과와 이력은 저장하지 않습니다.
6. **UI 검증:** 실제 iOS Safari 등 브라우저별 소리 정책과 디스플레이 줄바꿈·폭은 실기기에서 추가 확인이 필요합니다.
7. **접근성:** 키보드 탐색과 레이블을 제공하지만, 스크린리더 안내와 색상 대비는 추가 평가할 수 있습니다.
