01 / Features

단순하지만 필요한 기능은 탄탄하게

계산의 기본 기능에 오류 복구, 키보드 입력, 시각·청각 피드백을 더했습니다.

➕

사칙연산과 순차 계산

더하기·빼기·곱하기·나누기, 중간 결과 처리 및 연속 연산자 교체를 지원합니다.

↺

오류 복구와 입력 상태

0으로 나누기 시 Error를 표시하고 다음 숫자 입력에서 새 계산을 시작합니다.

◌

소수점·부호·백분율

소수점 중복을 막고 부호 전환과 현재 입력값을 100으로 나누는 백분율 기능을 제공합니다.

⌨

키보드 조작

숫자, 사칙연산, Enter, Backspace, Delete 등 키보드 입력으로 계산할 수 있습니다.

♫

Soft Click 효과음

별도 오디오 파일 없이 Web Audio API로 숫자·연산·등호·AC 클릭음을 합성합니다.

▣

반응형 유리 UI

4열 Grid 키패드, 웜 그레이 숫자, 작은 화면에 맞춘 간격과 글꼴 크기를 적용했습니다.

02 / Interaction Design

눈에 보이는 피드백, 귀에 들리는 반응

계산기 화면뿐 아니라 버튼을 누르는 경험까지 고려했습니다.

Visual Language

Warm Glassmorphism

베이지·피치 배경 위에 반투명 패널과 유리 버튼을 배치했습니다. 숫자는 웜 그레이로, 연산 키는 브라운으로 구분해 가독성을 높였습니다.

backdrop-filter CSS Gradient Responsive Grid

03 / Implementation

계산 흐름을 상태로 관리하다

입력에 따라 바뀌는 피연산자와 연산 상태를 분리해 예외 상황에서도 새로운 계산을 시작할 수 있도록 설계했습니다.

STEP 01

값 입력

currentInput에 숫자와 소수점을 구성합니다.

STEP 02

연산자 선택

firstOperand와 operator를 보관합니다.

STEP 03

결과 계산

calculate()로 연산하고 결과·과정을 표시합니다.

STEP 04

완료 / 복구

justCalculated와 오류 상태를 구분합니다.

04 / Verification

대표 입력 시나리오

아래 표는 실제 소스의 계산 규칙을 기준으로 정리한 기대 결과입니다.

시나리오 입력 예상 표시
기본 계산 5 + 3 = 8
새 계산 시작 5 + 3 = 다음 0.1 + 0.2 = 0.3
순차 계산 10 + 5 × 2 = 30
예외 처리 8 ÷ 0 = Error
오류 후 복구 Error 다음 5 + 3 = 8
백분율 50 × 10 % = 5
사운드 설정 ON → 새로고침 ON 유지

참고: 백분율은 현재 입력값 ÷ 100이며, 소수점은 12자리 유효숫자로 오차를 완화합니다. 수학식 연산자 우선순위·괄호·임의 정밀도 연산은 지원하지 않습니다. 실제 기기별 검증 결과는 별도로 확인해야 합니다.
